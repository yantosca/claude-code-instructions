# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Purpose

This is a personal, documentation-only repository of Claude Code instruction and guidance files (e.g. `CLAUDE.md` variants, notes on skills, workflows, and conventions). It contains no source code, build system, or tests — every file is Markdown.

## Working in this repo

- Content is a flat collection of `.md` files at the repo root; there is no build, lint, or test tooling to run.
- Keep line endings LF and files as plain text (enforced via `.gitattributes`).
- When adding a new instruction/reference document, prefer a new top-level `.md` file with a descriptive name over nesting into subdirectories, unless the collection grows large enough to warrant grouping.
