# Security Policy

This repository contains only Markdown documentation (Claude Code instructions and guidance files). It does not contain executable code, so there is no expected attack surface in the traditional sense.

## Reporting a Concern

If you believe a file in this repository contains sensitive information that should not be public (e.g. an accidentally committed secret or credential), or you have another security concern, please contact yantosca@seas.harvard.edu.

Please do not open a public issue for sensitive disclosures.
